--- ppt/slides/slide18.xml ---
 Navegador Es una aplicación de software diseñada para acceder, interpretar y visualizar sitios web en internet, traduciendo códigos como HTML, CSS y JavaScript en las páginas visuales, imágenes y videos que los usuarios interactúan. Actúa como intermediario entre el usuario y los servidores web. Ejemplos: Google Chrome Mozilla Firefox Funciones: Envía solicitudes Interpreta HTML Ejecuta JavaScript Renderiza CSS 

--- ppt/slides/slide19.xml ---
 Servidor Web Es un sistema informático (hardware y software) que almacena, procesa y entrega el contenido de los sitios web (HTML, imágenes, CSS, JS) a los navegadores de los usuarios. Actúa como intermediario, recibiendo peticiones HTTP/HTTPS del cliente y enviando de vuelta la información solicitada para que sea visualizada. Ejemplos: Apache HTTP Server Nginx Funciones: Recibe solicitudes HTTP Procesa datos Devuelve respuestas

 Qué es internet? Internet es una red mundial de redes que conecta millones de dispositivos alrededor del mundo. Interconecta computadoras, servidores, celulares, IoT. Funciona mediante protocolos de comunicación. Permite transferencia de datos a escala global. 

--- ppt/slides/slide4.xml ---
 Cómo funciona Internet? Internet funciona mediante: Dirección IP Protocolos (TCP/IP) Enrutamiento Servidores DNS 

--- ppt/slides/slide5.xml ---
 ¿Qué es la Web? La Web (World Wide Web) es un sistema de información que funciona sobre Internet y permite acceder a páginas web mediante un navegador. Internet es la infraestructura. La Web es un servicio que funciona sobre ella. 

--- ppt/slides/slide6.xml ---
 Servicios que funcionan sobre Internet Internet soporta múltiples servicios: Web (HTTP/HTTPS) Correo electrónico (SMTP) Transferencia de archivos (FTP) Streaming Juegos en línea La Web es solo uno de ellos. 

--- ppt/slides/slide7.xml ---
 ¿Qué es un sitio web? Un sitio web es un conjunto de páginas web interconectadas cuyo objetivo principal es informar. Características: Contenido mayormente estático No requiere autenticación obligatoria Navegación estructurada Ejemplos: Wikipedia CNN 

--- ppt/slides/slide8.xml ---
 ¿Qué es una aplicación web? Una aplicación web es un software que se ejecuta en el navegador y permite interacción avanzada con el usuario. Características: Interactividad Base de datos Procesamiento en servidor Autenticación Ejemplos: Google (Gmail) Facebook
