Experiencia de Usuario

UX
• Concepto de Experiencia de Usuario
• La Experiencia de Usuario (UX) se refiere a la percepción y sensación que
tiene una persona al interactuar con un sitio web o unaaplicación.
• No se trataúnicamente decómo se ve un sitio, sino dequé tanfácil, intuitivo y
agradable resulta utilizarlo.
• Un buendiseño UX busca:
• facilitar lainteracción del usuario
• reducir laconfusión
• mejorar lanavegación
• permitir que el usuario encuentreinformación rápidamente

Navegación básica del sitio
•¿Qué es la navegación en un sitio web?
• La navegación web es el sistema que permite al usuario
desplazarse entre las diferentespáginas o secciones de un sitio
web.
•Elementos comunes de navegación:
menú principal
enlaces internos
botones de acción
rutas de navegación (breadcrumbs)
pie de página con enlaces

Navegación básica del sitio
• La navegación debe permitir que el usuario entienda dónde está y
cómo llegar a otras secciones.
• Por ejemplo:
• Un sitio webtípico puede tener unmenú con opciones como:
• Inicio
• Servicios
• Productos
• Contacto
• Si el menú es confuso o está oculto, el usuario tendrá dificultades para
explorar el sitio.


Buenas prácticas de 
navegación
• Para mejorar la navegación de un sitio web se
recomienda:
mantener elmenú visible
usar nombres simples para las secciones
mantener la misma estructura en todas las
páginas
evitar demasiadas opciones en elmenú
colocar el menú en lugares comunes (parte
superior o lateral)


Buenas prácticas de 
navegación
• Los usuarios ya están acostumbrados a ciertos patrones de
navegación.
• Por ejemplo:
•menú en la parte superior
• logo que lleva al inicio
•botón de contacto visible
• Si cambiamos demasiado estas convenciones, el usuario puede
confundirse.

¿Qué es la jerarquía visual?
• Lajerarquía visual organiza los elementos de unapágina para que
el usuario pueda identificar fácilmente qué información es más
importante.
• Se construye mediante el uso de:
• tamaño de texto
• colores
• contraste
• espaciado
• posición de los elementos

¿Qué es la jerarquía visual?
• Cuando una persona entra a una página web no lee todo el
contenido inmediatamente.
• Primero escanea lapágina buscando:
• títulos grandes
• subtítulos
• imágenes
• Botones
• Si todos los elementos tienen el mismotamaño o color, el usuario
no sabe pordónde empezar.
LaJerarquía visual ayuda a guiar laatención del usuario.

Usabilidad
• La usabilidadse refiere a qué tan fácil es para un usuario utilizar 
un sistema o sitio web.
• Un sitio con buena usabilidad permite que el usuario:
•complete tareas fácilmente
• entienda la interfaz sin dificultad
•encuentre información rápidamente

Usabilidad
•Un diseño usable debe cumplir con varios principios:
• Simplicidad
• El diseño no debe ser complicado.
• Claridad
• Los botones y enlaces deben ser fáciles de identificar.
• Consistencia
• Los elementos deben comportarse de la misma forma en todo el sitio.

Usabilidad
• Ejemplos de mala usabilidad
• Problemas comunes de usabilidad:
•menús difíciles de encontrar
•textos demasiado pequeños
•demasiada información en una página
• botones que no se distinguen del resto del contenido
Un sitio con mala usabilidad genera frustración en el usuario y puede provocar 
que abandone la página.

Revisión de estructura completa HTML 
+ CSS
• Un sitio web bien estructurado combina:
• HTML: define la estructura del contenido
• CSS: define el diseño visual
• Ambos trabajan juntos para mejorar:
• organización del contenido
• navegación del sitio
• jerarquía visual
