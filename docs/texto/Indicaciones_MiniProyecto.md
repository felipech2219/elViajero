MINI PROYECTO 
Solución Web Interactiva para una Problemática Real 
Valor: 25% 
Semana de evaluación: Semana 7 
Modalidad: Individual o en parejas 
Tecnologías permitidas: HTML5, CSS3 y JavaScript 
DESCRIPCIÓN GENERAL  
El mini proyecto consiste en desarrollar una solución web funcional, responsiva, usable y navegable, 
construida únicamente con HTML, CSS y JavaScript, que atienda una problemática real identificada por la 
persona estudiante o equipo. 
El proyecto debe integrar los conocimientos desarrollados desde la semana 1 hasta la semana 7 del curso.  
El sitio no debe ser únicamente informativo. Debe permitir que el usuario realice acciones, reciba 
respuestas inmediatas, consulte información cargada desde JSON, registre datos y conserve información en 
el navegador mediante localStorage. 
PROPÓSITO DEL PROYECTO  
El propósito es que la persona estudiante demuestre que puede construir una solución web inicial, funcional 
e integrada, aplicando los fundamentos del desarrollo web sin depender de frameworks. 
La solución debe evidenciar: 
• Comprensión del problema planteado.  
• Diseño web organizado y responsivo.  
• Navegación clara entre páginas.  
• Interacción real con JavaScript.  
• Manipulación dinámica del DOM.  
• Validación de datos ingresados por el usuario.  
• Lectura y renderizado de información desde JSON.  
• Persistencia de información con localStorage.  
• Defensa técnica del código y de las decisiones implementadas.

REQUERIMIENTOS 
El mini proyecto debe estar compuesto por 3 páginas principales, completamente conectadas entre sí 
mediante el menú de navegación del sitio. 
Cada página debe cumplir una función específica dentro de la solución planteada y formar parte del flujo 
completo de interacción del usuario. No se aceptarán páginas vacías, repetidas, decorativas o sin 
funcionalidad real. 
Todas las páginas deben: 
• Mantener la misma identidad visual.  
• Compartir menú de navegación y pie de página.  
• Ser completamente responsivas.  
• Tener estructura HTML semántica.  
• Incluir interacción con JavaScript.  
• Mantener coherencia visual y funcional.  
• Permitir una navegación clara y comprensible

INTERACCIÓN COMPLEJA OBLIGATORIA  
La solución interactiva debe integrar como mínimo los siguientes comportamientos: 
1. Carga de datos desde JSON.  
2. Renderizado dinámico en pantalla.  
3. Búsqueda instantánea.  
4. Filtro por al menos un criterio.  
5. Selección, marcado o gestión de elementos.  
6. Generación de un resultado dinámico con JavaScript.  
7. Guardado de acciones o registros en localStorage.  
8. Recuperación automática de datos guardados.  
9. Validación de datos ingresados por el usuario.  
10. Mensajes visuales de éxito, error, advertencia o estado vacío.  
La funcionalidad debe estar conectada con la problemática real. No se aceptan botones, animaciones o 
cambios visuales que no aporten a la solución.
